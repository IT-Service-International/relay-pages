Community Edition — tested in real conditions. Validated in live Windows Server / Active Directory environments; offline tests also pass on macOS / PowerShell 7.6.9. This is not a production certification or a complete AD security audit.

01 / WHAT IT COLLECTS

  • Domain controller inventory
  • FSMO role ownership
  • Inbound replication metadata
  • DNS locator and address records
  • SYSVOL / NETLOGON access
  • Raw W32Time status
  • Direct privileged group membership
  • Inactive account candidates
  • Password policies
  • GPO inventory

Errors, skipped checks and incomplete results stay visible. There is no overall “healthy” score: a successful check confirms only its named observation. SYSVOL access does not prove DFSR consistency; time status needs manual interpretation; direct group membership is not a complete privilege graph.

02 / START WITH THE OFFLINE DEMO

Download and extract the ZIP, open PowerShell in the extracted toolkit folder, then run:

./Invoke-RelayADHealth.ps1 -Mode Demo

The demo reads bundled fictional observations only. It makes no directory queries and requires no RSAT or secrets. PowerShell 7 can run the demo on Windows, macOS or Linux. Open the report path printed at the end.

Expected demo exit code: 2. The sample deliberately includes a simulated DNS collection error and warnings to show how incomplete evidence is reported.

03 / LIVE REQUIREMENTS & DATA HANDLING

Runtime
Windows PowerShell 5.1, 64-bit. PowerShell 7 live mode is intentionally blocked in v0.1.
Prerequisites
Installed RSAT ActiveDirectory and GroupPolicy tools, approved domain connectivity and an existing Windows identity with the necessary read access.
Scope
One configured domain, plus forest role ownership and forest-root privileged groups. Explicit configuration, bounded collection and error reporting.
Data
Live reports can expose internal names, memberships and operational details. Store them privately; do not upload them to public repositories or send them through the initial enquiry form.

No remediation, dependency installation, telemetry or automatic report upload. Review the source and complete lab acceptance before use in an approved environment.
